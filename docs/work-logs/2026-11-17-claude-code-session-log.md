## 1. 작업 제목과 목적

**제목:** 대화 작업 기록을 지정된 8개 항목 구조의 Markdown으로 작성하고, 실제 파일로 저장한 뒤 GitHub 저장소에 반영한다.

**목적:** 작업 맥락을 저장소에 영구 보관하여, PC를 옮기거나 다음 AI 세션으로 넘어가도 동일한 기준으로 작업을 이어갈 수 있게 한다.

이 세션에서 사용자가 보낸 요청은 다음 두 부분이다.

**(2) 사용자가 명시한 주의사항(원문 지시 요약)**

- 확인할 수 없는 과거 내용은 추측하지 말 것
- 주민등록번호, 고객 실명, 계좌번호, 인증정보는 제외할 것
- 실제 파일 저장·GitHub 업로드를 하지 않았다면 완료했다고 쓰지 말 것

**(3) 후속 지시**

- GitHub 저장소 주소: `https://github.com/teru101725-droid/ai-workspace`

## 6. 미완료 사항과 확인이 필요한 내용

- `gh` CLI는 여전히 미로그인 상태다. 향후 PR 생성·이슈 조회 등이 필요하면 `gh auth login`이 필요하다.
- GitHub 커넥터(앱) 설치·쓰기 권한은 이 세션에서 변경하지 않았다. 커넥터 기반 자동 업로드가 필요하면 별도 설정이 필요하다.
- 이 세션 이전의 상세 작업 이력(법령·판례 검토, 블로그·강의·프로그램 개발 진행도 등)은 확인하지 않았다. 저장소의 선행 문서에 서술된 내용 외의 진행 상태는 검증되지 않았다.
- 선행 문서가 언급하는 `output/blog/PUBLISHING-PREFERENCES.md`, `output/blog/THURSDAY-VAT-PREFERENCES.md`는 이 저장소에 존재하지 않는다. 다른 로컬 경로에 있는 파일로 보이며, 이 세션에서 열람하지 않았다.
- 저장소에 `README.md`나 작업 기록 색인이 없다. 기록이 늘어나면 색인 문서가 필요한지 확인이 필요하다.
